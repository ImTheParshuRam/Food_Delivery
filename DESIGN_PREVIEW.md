# 🎨 FoodHub - Visual Design Preview

## Color Palette

### Primary Colors
- **Primary Orange**: `#FF6B35` - Used for CTAs, highlights, and brand identity
- **Primary Dark**: `#E85A2A` - Hover states and emphasis
- **Primary Light**: `#FF8C5F` - Subtle backgrounds

### Secondary Colors
- **Turquoise**: `#4ECDC4` - Secondary actions and accents
- **Golden Yellow**: `#FFD93D` - Highlights and badges
- **Success Green**: `#6BCF7F` - Success messages and confirmations

### Gradients
- **Primary Gradient**: Orange to Yellow (`#FF6B35` → `#F7931E`)
- **Secondary Gradient**: Turquoise to Teal (`#4ECDC4` → `#44A08D`)
- **Dark Gradient**: Deep blue tones (`#1A1A2E` → `#16213E`)

## Component Styles

### Buttons
- **Primary**: Orange gradient with white text, shadow, hover lift
- **Secondary**: Turquoise gradient with white text
- **Outline**: Transparent with orange border, fills on hover
- **Ghost**: Transparent, subtle background on hover

### Cards
- **White background** with rounded corners (16px)
- **Shadow** that increases on hover
- **Smooth transitions** (300ms)
- **Hover lift** effect (translateY -8px)

### Forms
- **Inputs**: White background, gray border, orange focus ring
- **Labels**: Uppercase, small, with icons
- **Validation**: Red error messages below fields

### Navbar
- **Sticky** at top
- **White background** with shadow
- **Cart badge**: Orange circle with count
- **User dropdown**: Appears on hover
- **Mobile menu**: Slides in from top

## Animations

### Floating Cards (Home Page)
```
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
```

### Hover Effects
- Cards: Lift up 8px + increase shadow
- Buttons: Lift up 2px + ripple effect
- Images: Scale 1.1 on hover

### Loading Spinner
- Rotating circle with orange accent
- Smooth 0.8s rotation

### Page Transitions
- Fade in from bottom (20px)
- 600ms ease-out timing

## Responsive Behavior

### Mobile (< 640px)
- Single column layouts
- Full-width buttons
- Stacked navigation
- Hamburger menu
- Larger touch targets

### Tablet (640px - 968px)
- 2-column grids
- Balanced layouts
- Visible navigation

### Desktop (> 968px)
- 3-4 column grids
- Sidebar layouts
- Hover effects
- Full navigation

## Typography Scale

- **Hero Title**: 64px (clamp 40px-64px)

- **Section Title**: 32px (clamp 28px-32px)
- **Card Title**: 24px
- **Body**: 16px
- **Small**: 14px
- **Tiny**: 12px

## Spacing Scale

- **xs**: 4px
- **sm**: 8px
- **md**: 16px
- **lg**: 24px
- **xl**: 32px
- **2xl**: 48px
